Streaming Engagement Analysis

This project focuses on multi-table relational database analysis. The goal is to track how users interact with the streaming platform, identify popular movie genres, and find opportunities to upsell basic users to premium tiers.

Database Structure
The project uses three tables:
- users: Contains account names and subscription plan details.
- movies: Contains the movie catalog and genres.
- watch_log: Tracks the actual minutes spent watching content.

Skills Shown
- Connecting tables using INNER JOIN
- Combining data from 3 separate tables at once
- Using WHERE and HAVING to filter data at different stages
- Writing CASE WHEN statements to categorize user behavior
